# مساعد العمل الذكي - AI Work Assistant

تطبيق ويب متكامل يجمع بين متصفح ويب وحاسوب ذكي (AI) لمساعدتك في أداء مهامك على الإنترنت.

## ✨ المميزات

- **متصفح ويب مدمج**: افتح أي موقع وتصفحه مباشرة داخل التطبيق
- **مساعد ذكي بجانب الصفحة**: اطرح أسئلة عن محتوى الصفحة الحالية
- **فهم تلقائي للمحتوى**: يقرأ المساعد محتوى الصفحة ويفهم السياق
- **شرح الخطوات**: اطلب شرح كيفية عمل أي شيء على الموقع
- **تلخيص سريع**: احصل على ملخص الصفحة بنقرة واحدة
- **مقترحات ذكية**: اسأل ماذا تفعل بعد ذلك
- **واجهة عربية**: تماماً مصممة للغة العربية

## 🚀 البدء السريع

### المتطلبات
- Node.js (الإصدار 14 أو أحدث)
- مفتاح API من OpenAI

### التثبيت

1. **استنسخ المستودع**
```bash
git clone https://github.com/aqejar2015-ops/ai-work-assistant.git
cd ai-work-assistant
```

2. **ثبت المتطلبات**
```bash
npm install
```

3. **أنشئ ملف `.env`** من النموذج
```bash
cp .env.example .env
```

4. **أضف مفتاح API الخاص بك**
```
OPENAI_API_KEY=sk-xxx...xxx
PORT=3000
```

الحصول على مفتاح API من OpenAI: https://platform.openai.com/api-keys

### تشغيل التطبيق

```bash
npm start
```

ثم افتح المتصفح وانتقل إلى:
```
http://localhost:3000
```

## 📖 كيفية الاستخدام

### 1. تحميل موقع
- أدخل رابط الموقع في حقل URL
- انقر "تحميل" أو اضغط Enter

### 2. اطرح سؤال
- اكتب سؤالك في صندوق المحادثة
- المساعد سيقرأ محتوى الصفحة ويجيب

### 3. الأزرار السريعة
- **📋 ملخص الصفحة**: احصل على ملخص سريع
- **❓ ماذا أفعل؟**: اسأل عن الخطوة التالية
- **مسح**: امسح المحادثة والبدء من جديد

## 🔧 التطوير

### إضافة ميزات جديدة

1. **شرح أفضل للصفحات**: تحسين استخراج محتوى الصفحة
2. **حفظ المحادثات**: قاعدة بيانات لحفظ السجل
3. **ملفات شخصية**: تخزين إعدادات المستخدم
4. **مساعدة متقدمة**: تنفيذ إجراءات آمنة على الموقع

### الأوامر المتاحة

```bash
npm start      # تشغيل الخادم
npm dev        # تشغيل في وضع التطوير
```

## ⚠️ التحذيرات والأمان

- **لا تحفظ مفاتيح API**: أبداً لا تضع مفاتيح API في الكود
- **استخدم متغيرات البيئة**: ضع المفاتيح في `.env` فقط
- **حماية iframe**: بعض المواقع تمنع العرض داخل iframe
- **لا تنسخ كلماتك المرورية**: لا تكتب كلمات المرور في الدردشة
